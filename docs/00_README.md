# Motionbase — Project Documentation Kit

**Product:** Motionbase  
**Positioning:** Application design inspiration + design intelligence + motion UI reference + AI implementation prompt generation.

This package is a practical product and engineering blueprint. It is not a finished software implementation. Use it as the source of truth when planning and building the application.

## Images
The `images/` folder contains original planning diagrams and a low-fidelity reference detail wireframe. These are explanatory assets, not final UI screenshots.

## Important product principles
- A screenshot is evidence of appearance, not proof of hidden implementation.
- Distinguish observed facts from AI estimates.
- Store source attribution and usage rights for every reference.
- Do not execute untrusted code in the main application origin.
- Optimize for perceived speed and stable frame pacing; do not promise guaranteed 120 FPS.
- Start with a modular monolith and split services only when operational evidence justifies it.

## Suggested first build
Deliver discovery, search, reference detail pages and admin content management first. Then add design analysis, Motion Lab and Prompt Studio. A curated library of 50–100 high-quality references is more useful than a huge low-quality collection.
