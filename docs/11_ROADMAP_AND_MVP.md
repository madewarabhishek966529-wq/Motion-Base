# 11. Roadmap and MVP Prioritization

## Phase 0 — Product setup
- Confirm brand, domain and legal approach.
- Select hosting, database and storage.
- Establish design tokens and repository.
- Set up CI, linting, formatting and tests.

## Phase 1 — Useful MVP
Build:
- Landing and discovery.
- Search and filters.
- Reference detail pages.
- Screen galleries.
- Admin reference management.
- Attribution and rights metadata.
- User auth and bookmarks.

Content goal: curate 50–100 high-quality references with permission or a reviewed basis for use.

Do not begin with AI analysis of thousands of images.

## Phase 2 — Design Intelligence
- Manual token editor.
- Palette extraction.
- Gradient definitions.
- Typography and layout notes.
- Provenance/confidence labels.
- Screen flow.

## Phase 3 — Motion and Components
- Curated animation library.
- Isolated previews.
- Motion metadata.
- React and Flutter examples.
- Component library.

## Phase 4 — Prompt Studio
- Framework-neutral prompt IR.
- Four tool adapters.
- Four scope adapters.
- Four framework adapters.
- Editable prompt preview.
- Copy and Markdown export.
- Prompt quality tests.

## Phase 5 — Community and advanced AI
- Submissions and moderation.
- Public collections.
- Comments and likes.
- AI-assisted analysis with human review.
- Similar-reference discovery.

## Phase 6 — Production hardening
- Load and security testing.
- Accessibility audit.
- Observability and alerts.
- Backup/restore rehearsal.
- Cost controls.
- Content moderation operations.

## Prioritization rule
Build the reference data model and content workflow before the AI prompt generator. Prompt quality depends on structured, trustworthy reference data.
