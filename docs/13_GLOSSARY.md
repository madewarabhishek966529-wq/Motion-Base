# 13. Glossary

**Reference:** An app design or product interface used for discovery and analysis.

**Screen:** One distinct view or state in an application.

**Design DNA:** The visual system behind a reference: color, typography, spacing, layout, effects and component patterns.

**Design token:** A named reusable design value such as a color, spacing unit or radius.

**Motion specification:** Structured information about an animation's trigger, target, duration, easing, direction and behavior.

**Micro-interaction:** Small feedback interaction such as a button press, toggle or input validation.

**Screen flow:** The relationships and transitions between application screens.

**Prompt IR:** A structured, framework-neutral representation used to create tool-specific prompts.

**Provenance:** Where a piece of information came from and how it was obtained.

**Observed:** Directly visible in supplied reference material.

**Extracted:** Computed from media using deterministic processing.

**Inferred:** Estimated by AI or human interpretation from incomplete evidence.

**Manually verified:** Reviewed and confirmed by a curator or qualified reviewer.

**Reduced motion:** An alternate experience for users who prefer less animation.

**Core Web Vitals:** Google's user-experience metrics including LCP, INP and CLS.
